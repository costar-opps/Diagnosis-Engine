## Purpose

定义诊断控制台与后端之间的数据契约与占位语义：前端依赖哪些接口、占位实现应返回什么、以及接口不可用时界面如何在保持可用的同时避免把样例数据伪装成真实数据。

## ADDED Requirements

### Requirement: 控制台依赖的接口集合

系统 SHALL 为诊断控制台提供以下接口：项目列表查询、单项目概览查询、诊断发起、报告反馈提交。

平台层数据 MUST 继续使用既有的监控仪表盘接口，MUST NOT 为其新增重复接口。

#### Scenario: 查询项目列表

- **WHEN** 控制台请求项目列表
- **THEN** 接口返回各项目的标识、名称、可诊断状态，不可诊断时附带原因

#### Scenario: 查询项目概览

- **WHEN** 控制台以某项目标识请求概览
- **THEN** 接口返回该项目的业务指标、活跃异常与最近变更信息

#### Scenario: 平台层复用既有接口

- **WHEN** 控制台加载平台层
- **THEN** 请求既有的监控仪表盘接口，不调用新增接口

### Requirement: 占位实现的语义

占位接口 MUST 返回结构完整、字段齐备的响应，使前端无需为占位阶段编写特殊分支。

占位接口 MUST 在响应中标明其为占位数据，MUST NOT 让前端把占位响应误判为真实数据。

诊断发起接口在占位阶段 MUST 明确表示尚未实现，MUST NOT 返回伪造的诊断报告。

#### Scenario: 占位响应结构完整

- **WHEN** 前端调用占位的项目概览接口
- **THEN** 响应包含与正式实现一致的字段结构

#### Scenario: 占位数据可识别

- **WHEN** 前端收到占位接口的响应
- **THEN** 响应中带有占位标记，前端据此在界面上标注

#### Scenario: 诊断发起未实现

- **WHEN** 前端在占位阶段调用诊断发起接口
- **THEN** 接口返回未实现的明确状态，不返回伪造报告

### Requirement: 未注册项目的响应

以未注册的项目标识请求项目概览时，接口 MUST 返回明确的未找到状态，MUST NOT 返回其他项目的数据或空结构。

#### Scenario: 查询未注册项目

- **WHEN** 前端以不存在的项目标识请求概览
- **THEN** 接口返回未找到状态，前端展示相应提示

### Requirement: 数据降级与标注

接口不可用时，界面 SHALL 回落到内置样例数据以保持可用，且 MUST 在对应分区显著标注当前展示的是样例数据。

降级 MUST 按分区独立生效，一个分区降级 MUST NOT 导致其他分区一并降级。

降级状态下，MUST 禁用会产生真实副作用的操作入口。

#### Scenario: 项目概览接口不可用

- **WHEN** 项目概览接口请求失败
- **THEN** 项目层展示内置样例数据，并在该分区标注为样例数据

#### Scenario: 降级不扩散

- **WHEN** 项目层降级为样例数据而平台层接口正常
- **THEN** 平台层继续展示真实数据，不显示样例标注

#### Scenario: 降级时禁用写操作

- **WHEN** 界面处于样例数据状态
- **THEN** 采纳与驳回等提交类入口处于禁用状态

### Requirement: 字段命名一致

前端渲染所依赖的字段命名 SHALL 与后续正式实现保持一致，使正式接口就位后无需修改渲染逻辑。

#### Scenario: 替换数据来源不改渲染

- **WHEN** 占位接口被替换为正式实现且字段命名不变
- **THEN** 前端无需修改渲染逻辑即可展示真实数据
