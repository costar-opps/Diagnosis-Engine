# Diagnosis-Engine 项目启停指南（Windows）

> **新手启动请优先阅读：[启动手册.md](./启动手册.md)**（含完整命令、开哪个窗口、成功标志）  
> 本文侧重：**关电脑怎么停服务** + 启停速查。

> 适用环境：本机开发（Windows + PowerShell）  
> 先进入克隆下来的仓库根目录再执行命令。

---

## 一、关电脑前需要停哪些服务？

本项目运行时通常有 **4 类进程**，建议按下面顺序手动停止，避免端口占用、文件锁或 Docker 数据异常。

| 序号 | 服务 | 端口 | 启动方式 | 是否必停 |
|------|------|------|----------|----------|
| 1 | **Spring Boot 后端** | 9900 | IDE Run / `mvn spring-boot:run` | ✅ 建议停 |
| 2 | **cls-mcp-server（MCP）** | 3000 | `scripts\start-mcp.ps1` 窗口 | ✅ 建议停 |
| 3 | **Prometheus** | 9090 | `scripts\start-prometheus.ps1` 后台进程 | ✅ 建议停 |
| 4 | **Milvus（Docker）** | 19530 等 | `docker compose -f vector-database.yml up -d` | ⚠️ 可选 |

> **说明**：直接关机时上述进程大多会被系统杀掉，但下次启动可能遇到「端口仍被占用」或 Docker 容器状态异常，因此**正常下班建议手动停一遍**。

---

### 1.1 停止 Spring Boot（9900）

**若在 IDE（IntelliJ IDEA）中运行：** 点击红色 Stop 按钮即可。

**若在 PowerShell 中运行 `mvn spring-boot:run`：** 在该窗口按 `Ctrl + C`。

**若不确定是否还在运行，可强制结束占用 9900 端口的进程：**

```powershell
Get-NetTCPConnection -LocalPort 9900 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
```

---

### 1.2 停止 cls-mcp-server（3000）

在运行 `start-mcp.ps1` 的 PowerShell 窗口按 **`Ctrl + C`**。

若窗口已关但服务仍在：

```powershell
Get-NetTCPConnection -LocalPort 3000 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
```

---

### 1.3 停止 Prometheus（9090）

Prometheus 由脚本在后台启动，PID 保存在：

```
monitoring\prometheus\prometheus.pid
```

**推荐停法：**

```powershell
cd "."
$pidFile = "monitoring\prometheus\prometheus.pid"
if (Test-Path $pidFile) {
    $pid = Get-Content $pidFile
    Stop-Process -Id $pid -Force -ErrorAction SilentlyContinue
    Remove-Item $pidFile -Force -ErrorAction SilentlyContinue
    Write-Host "Prometheus 已停止 (PID=$pid)"
} else {
    Write-Host "未找到 PID 文件，尝试按端口结束..."
    Get-NetTCPConnection -LocalPort 9090 -ErrorAction SilentlyContinue |
      Select-Object -ExpandProperty OwningProcess -Unique |
      ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
}
```

---

### 1.4 停止 Milvus（Docker，可选）

若希望 Docker 也一起干净关闭：

```powershell
cd "."
docker compose -f vector-database.yml down
```

若只是关电脑、下次还要用向量库，也可以 **只停 Java/MCP/Prometheus**，Milvus 容器保持运行（需 Docker Desktop 未退出）。

---

### 1.5 关电脑前快速检查清单

```powershell
# 查看关键端口是否仍被占用（无输出表示已释放）
9900, 3000, 9090, 19530 | ForEach-Object {
    $conn = Get-NetTCPConnection -LocalPort $_ -State Listen -ErrorAction SilentlyContinue
    if ($conn) { Write-Host "端口 $_ 仍被占用 (PID=$($conn.OwningProcess))" -ForegroundColor Yellow }
    else { Write-Host "端口 $_ 已释放" -ForegroundColor Green }
}
```

## 二、下次启动前需要做什么准备？

### 2.1 一次性/偶尔检查

| 检查项 | 说明 |
|--------|------|
| **Java 17 + Maven** | `java -version`、`mvn -version` 正常 |
| **Node.js + npx** | MCP 需要，`node -v`、`npx -v` 正常 |

### 2.2 确认 cls.env 已配置

```powershell
cd "."
# 若还没有 cls.env：
# Copy-Item cls.env.example cls.env
# 然后编辑 cls.env 填写 DASHSCOPE_API_KEY；需要日志证据时再填腾讯云 CLS 项
```

## 三、下次启动完整步骤（推荐顺序）

> **原则：先基础设施，再 MCP，最后启动后端。**  
> MCP 与后端各占用一个 PowerShell 窗口，不要关闭。

### 步骤 0：进入项目目录

```powershell
cd "."
```

---

### 步骤 1：启动 Docker Desktop（若未运行）

打开 **Docker Desktop**，等待左下角状态为 **Running**。

---

### 步骤 2：启动 Milvus 向量库

```powershell
cd "."
docker compose -f vector-database.yml up -d
docker compose -f vector-database.yml ps
```

**验证：** Milvus 端口 `19530` 可连接（可选访问 Attu 等工具）。

---

### 步骤 3：启动 Prometheus

```powershell
cd "."
.\scripts\start-prometheus.ps1
```

**验证：**

- http://localhost:9090/targets → `super-biz-agent` 状态为 **UP**
- http://localhost:9090/alerts → 可查看告警规则

> 首次运行会自动下载 Prometheus 二进制到 `monitoring\prometheus\bin\`。

---

### 步骤 4：启动 cls-mcp-server（新开 PowerShell 窗口）

```powershell
cd "."
.\scripts\start-mcp.ps1
```

看到类似 `Started cls-mcp-server in sse transport on port 3000` 即成功。

**验证：** http://localhost:3000 （或 SSE 端点 `/sse` 可连通）

> ⚠️ **保持此窗口运行**，关闭窗口即停止 MCP。

---

### 步骤 5：启动 Spring Boot 后端（再开一个 PowerShell 窗口，或使用 IDE）

**方式 A：脚本启动（推荐，自动加载 cls.env）**

```powershell
cd "."
.\scripts\start-app-with-cls.ps1
```

**方式 B：IntelliJ IDEA**

1. 打开项目，运行 `org.example.Main`
2. 若 CLS 未生效，在 Run Configuration 中加载 `cls.env` 环境变量，或先执行：

```powershell
Get-Content cls.env | ForEach-Object {
    if ($_ -match '^([^#=][^=]*)=(.*)$') {
        Set-Item -Path "Env:$($matches[1].Trim())" -Value $matches[2].Trim()
    }
}
```

**验证：**

| 地址 | 预期 |
|------|------|
| http://localhost:9900 | 打开 Web 界面 |
| http://localhost:9900/api/monitoring/status | 返回本机指标 JSON |
| http://localhost:9900/api/monitoring/cls-verify | `success: true` |
| http://localhost:9900/actuator/prometheus | 有 `host_cpu_usage_percent` 等指标 |

## 五、常见问题

### Q1：9900 端口被占用

```powershell
Get-NetTCPConnection -LocalPort 9900 -ErrorAction SilentlyContinue |
  Select-Object OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

### Q2：AI Ops 报 MCP / topic_id 错误

1. 确认 **步骤 4 MCP 窗口** 仍在运行  
2. 确认 `cls.env` 中 `CLS_TOPIC_ID` 为 UUID（不是 `system-metrics`）  
3. 访问 http://localhost:9900/api/monitoring/cls-verify 检查 Topic

### Q3：Prometheus target 为 DOWN

1. 确认后端 **9900 已启动**  
2. 访问 http://localhost:9900/actuator/prometheus 是否有 metrics  
3. 重新执行 `.\scripts\start-prometheus.ps1`

### Q4：Milvus 连接失败

```powershell
docker compose -f vector-database.yml ps
docker compose -f vector-database.yml up -d
```

### Q5：DashScope 报 Arrearage（欠费）

检查 `cls.env` 中的 `DASHSCOPE_API_KEY` 是否有效，以及阿里云百炼账户是否有余额或免费额度。
